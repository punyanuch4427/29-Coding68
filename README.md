เขียนโปรแกรม

##The beginning of good health project
> โปรแกรมนี้เกี่ยวกับการคำนวณหาปริมาณน้ำที่เหมาะสมกับร่างกายของเรา

##introduction
> เนื่องจากการดื่มน้ำเป็นสิ่งสำคัญที่หลายคนอาจละเลย การดื่มน้ำที่ดีคือจุดเริ่มต้นของสุขภาพที่ดี การดื่มน้ำให้เพียงพอต่อร่างกายในหนึ่งวันนั้นส่งผลดีต่อร่างกายถ้าหากดื่มน้ำได้ไม่เพียงพออาจก่อให้เกิดปัญหาทางสุขภาพขึ้นได้ แต่เมื่อสำรวจพบว่ามีหลายคนที่ยังไม่ทราบว่าตัวเองควรดืมน้ำปริมาณเท่าไหร่ต่อวัน และด้วยเหตุผลที่ได้กล่าวมาเบื้องต้นนี้ จึงจุดประกายให้ดิฉันเขียนโปรแกรมนี้ขึ้นมา
มีเป้าหมายเพื่อให้ทุกคนหันมาสนใจการดื่มน้ำในปริมาณที่เหมาะสม และสามารถทราบปริมาณน้ำที่ควรดื่มในแต่ละวันของตนเอง

##Features
1.คำนวณปริมาณน้ำ
2.แปลงค่าน้ำเปรียบเทียบเป็นขวด
3.แปลงค่าน้ำเปรียบเทียบเป็นแก้ว
