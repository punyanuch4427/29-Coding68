📌 1. ที่มาและความสำคัญ (Introduction)

เนื่องจากการดื่มน้ำเป็นสิ่งสำคัญที่หลายคนอาจละเลย การดื่มน้ำให้เพียงพอต่อร่างกายในหนึ่งวันนั้นส่งผลดีต่อร่างกายถ้าหากดื่มน้ำได้ไม่เพียงพออาจก่อให้เกิดปัญหาทางสุขภาพขึ้นได้ แต่เมื่อสำรวจพบว่ามีหลายคนที่ยังไม่ทราบว่าตัวเองควรดืมน้ำปริมาณเท่าไหร่ต่อวัน จึงจุดประกายให้ดิฉันเขียนโปรแกรมนี้ขึ้นมา

ปัญหาที่พบ:มีหลายคนที่ยังไม่ทราบว่าตัวเองควรดื่มน้ำปริมาณเท่าไหร่ต่อวันรวมถึงตัวเองด้วย
เป้าหมาย: เพื่อให้ทุกคนหันมาสนใจการดื่มน้ำในปริมาณที่เหมาะสม และสามารถทราบปริมาณน้ำที่ควรดื่มในแต่ละวันของตนเอง
